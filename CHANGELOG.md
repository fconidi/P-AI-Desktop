## [1.0.0] - 2025-12-15

### Added / Aggiunto
- **EN:** Initial release of Perplexity Desktop for Linux
- **IT:** Rilascio iniziale di Perplexity Desktop per Linux

- **EN:** Electron-based wrapper for Perplexity AI web interface
- **IT:** Wrapper basato su Electron per l'interfaccia web di Perplexity AI

- **EN:** Global keyboard shortcut (Ctrl+Shift+P) to show/hide application window
- **IT:** Scorciatoia globale da tastiera (Ctrl+Shift+P) per mostrare/nascondere la finestra dell'applicazione

- **EN:** External link handling - opens non-Perplexity URLs in system browser
- **IT:** Gestione dei link esterni - apre gli URL non-Perplexity nel browser di sistema

- **EN:** Linux packaging support (.deb and AppImage formats)
- **IT:** Supporto per il packaging Linux (formati .deb e AppImage)

- **EN:** Application icon and desktop integration
- **IT:** Icona dell'applicazione e integrazione con il desktop

### Security / Sicurezza
- **EN:** External links automatically open in system browser for enhanced security
- **IT:** I link esterni si aprono automaticamente nel browser di sistema per maggiore sicurezza
